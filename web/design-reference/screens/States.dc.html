The lens: four states

FIX-M001. Proceed with normal checks.
FIX-M003. Below 70: read every reason.
FIX-M004. Coverage under 45%: the number is greyed, the ask is evidence.
FIX-M005. Consent revoked: no score, no decision.

Decision actions

There is no Approve or Decline button anywhere, and the API refuses those words. Record decision stays disabled until an override has a written reason.
